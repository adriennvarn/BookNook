# BookNook
## Your book review database

BookNook is a demonstration React application, a capstone project for Flatiron School. This application helps you find books you've read and store your personal ratings and reviews.

### Features
- Simple, functional UI
- Locally stored database
- Search OpenLibrary with external API support

## Installation
Fork and clone the repository.
`cd` into the cloned folder and run `npm install`.
Once installation is complete, run `npm run dev` to start the local dev server.
Navigate to `http://localhost:5173` to view the site.
